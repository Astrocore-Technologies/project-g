# Ручная проверка GDD 01 — Буковая долина

Из корня проекта, PowerShell 7:

```powershell
pwsh -File tools/Start-CombatTest.ps1
# Два игрока: PvP, группа, лечение союзника и воскрешение
pwsh -File tools/Start-CombatTest.ps1 -Clients 2
```

Каждый запуск создаёт новую SQLite-базу и новые личности в `.artifacts/combat-test/<id>`.
Обычный запуск собирает сервер в отдельный каталог этого сеанса, поэтому работающий
Development-сервер не блокирует проверку новой сборки.
Старые сохранения не используются. Сервер — 20 TPS, компенсация задержки выключена.
После закрытия всех окон игры завершается только сервер этого запуска. Повторный запуск
возвращает чистый набор, включая печать восстановления и прочность оружия.

Обычный Development-сервер тоже начинает новых персонажей в Буковой долине с этим набором;
его отдельная база — `.data/project-g-combat01-beech.db`, личность сцены — `combat01-beech`.
`CombatTest:Enabled=false` отключает выдачу и дополнительные цели. Balance Studio и smoke
с собственным контентом используют свои наборы. Боевые правила и обычный `prototype.json`
этой площадкой не изменяются.

## Рядом со спавном

| Место | X / Z | Для чего |
|---|---|---|
| Старт и respawn | −425 / 330 | Безопасная опушка |
| Обычный манекен | −414 / 321 | Урон, дальность, фазы атак |
| Три учебные цели | около −414 / 325 | AoE, все виды контроля, ACR, Bleed/DoT; не атакуют |
| Обычный противник | −403 / 315 | Block, Parry, Dodge, прерывания, Threat |
| Босс | −393 / 300 | Телеграфы, область, уход за leash, смерть |

Добавленные боевые цели возрождаются через 5 секунд. Учебные цели имеют 10 000 HP и
ускоренную регенерацию для долгой проверки. Базовые параметры противника и босса обычные.
Указатели площадки находятся в редактируемой сцене `BeechValley.tscn`.

## Персонаж и управление

Характеристики по 10, включая WIS, 18 свободных очков; профессия Мечник уже доступна.
В `I` лежат меч с износом, лук, посох, кинжалы, двуручное оружие, щит, броня и печать Эхо.
Меч и броня надеты. Смена оружия запрещена во время In Combat; двуручное, лук и посох
требуют сначала снять щит. Для безоружной атаки снимите оружие.

ЛКМ — ручной Basic, ПКМ — движение, Space — Dodge, Tab — удержание Block.
При нажатии Tab направление фиксируется на курсор до отпускания: дальнейшее перемещение
курсора и ходьба назад его не меняют. Чтобы выбрать новое направление, отпустите и нажмите Tab снова.
Shift — Parry.
`K` → навыки: назначайте изученные навыки на Q/W/E/R/A/S/D/F.
Сразу на панели: снаряд с тремя зарядами, область, Charged, Channel, лечение, щит,
Выпад и Stun. Остальные изученные навыки доступны для перестановки через K.

В списке есть все приёмы Мечника и явно подписанные проверочные примеры:
Instant, Cast с ценой HP, Charged, Channel, Hold, Toggle, Passive;
лечение/HoT/щит, DoT, очищение, рассеивание, воскрешение, Life/Mana Steal и отражение,
сброс всех зарядов снаряда и все 14 видов контроля. Проверочные числа — локальный QA-контент,
не утверждение нового постоянного баланса. «Восстановление ресурсов» бесплатно повышает
регенерацию на 5 секунд; назначьте его через K, если нужно быстро продолжить проверку.

Charged: держите кнопку, отпустите для выпуска; Esc/ПКМ отменяют подготовку.
Channel: Esc отменяет; Hold завершается при отпускании; Toggle — повторным нажатием.
Passive действует без ячейки. ACR проверяйте повторным контролем, затем паузой 12 секунд
после окончания последнего контроля категории. Компенсация задержки намеренно выключена.

`F3`: три готовых Эхо Миры. Призыв каждого занимает 10 секунд и 20 MP; T/Y/U — Signature.
Печать из I восстанавливает погибшее Эхо вне боя; затем нужен новый призыв.
Обычный отзыв и перестановка экипировки доступны после выхода из боя.

## Проверки с двумя окнами

Для PvP выйдите из безопасного прямоугольника X [−437, −413], Z [318, 342], включите
доступный режим PvP через окно V. Для поддержки создайте группу через окно N:
лечение, щиты и воскрешение по умолчанию работают на себя и свою группу.
Для проверки смерти/разбора дайте противнику убить персонажа; воскрешение — пока тело
существует 60 секунд, respawn — через 60 секунд с 50% HP/MP. Журнал и разбор видны владельцу.

При проверке disconnect тело и активные Эхо продолжают жить в мире 60 секунд.
Для проверки восстановления после перезапуска используйте обычный Development-сервер
с его постоянной тестовой базой; launcher намеренно создаёт новую базу при каждом запуске.

## Настройка

- `Content.Server/Data/Development/combat-test.json`: набор, панель, позиции целей и QA-навыки/эффекты.
- `Content.Server/Data/prototype.json`: утверждённые боевые определения; площадка их читает.
- `Content.Client/Scenes/Regions/Linvel/BeechValley.tscn`: визуальные указатели.
- `Content.Server/appsettings.Development.json`: стартовый регион и включение площадки.

Ручная площадка обеспечивает доступ к сценариям, но не заменяет проверку всех правил
в игре. Сетевые задержки и аварийное восстановление проверяются отдельными сценариями.
