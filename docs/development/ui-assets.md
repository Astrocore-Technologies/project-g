# Подключение исходников UI

Статус: ресурсы Project_G_UI_Source_Kit подключены к восьми живым экранам игры. Компоновки используют реальные серверные данные и команды; отсутствующие игровые системы показывают пустое или недоступное состояние.
Сгенерированные портреты из обсуждения не подключены к игровому персонажу. Макеты не включают несуществующие игровые системы.

## Подключённый Source Kit

Источник сохранён в Project_G_UI_Source_Kit без изменений. Команда python3 tools/import-ui-source-kit.py повторно экспортирует ресурсы темы и каталог; ручные правки этих сгенерированных файлов будут заменены.

- 40 SVG-иконок из godot/icons; tint определяется темой. Все доступны по icon.<имя>.
- 11 SVG-компонентов: панели, состояния кнопок, рамки предметных слотов. Демонстрационный текст и рисунки предметов удалены из runtime-компонентов; текст остаётся в Godot Label/Button.
- Палитра design/tokens.json, системные семейства шрифтов и nine-patch поля перенесены в fantasy-skin.tres. Конкретных файлов шрифтов в пакете нет, поэтому метрики fallback могут отличаться между компьютерами.
- 53 ключа каталога, включая существующие skill ID, категории экипировки и навигацию. Связь конкретной иконки навыка — презентационное соответствие, без переноса демонстрационных боевых параметров.
- Растровые изображения мира и портреты, фиктивные предметы/имена/награды, демо-GDScript и полноэкранные SVG не подключены к runtime.

Расхождения пакета с игрой: легендарка без bound может выпасть; действующие клавиши K/I/L/F2 и T/Y/U сохранены. Защита от продажи в HTML-демо не является серверным bound-флагом. География демо не заменяет игровую карту.

## Где работать

- Content.Client/UI/Theme/fantasy-skin.tres — палитра, шрифты, StyleBox для панелей/кнопок/слотов, рамки портретов и миникарты.
- Content.Client/UI/Theme/art-catalog.tres — массив UiArtEntry: Key + Texture и/или Model + Attribution.
- Content.Client/Assets/UI/ — оптимизированные игровые экспорты.
- art-source/ui/ — исходные редактируемые файлы и сведения о происхождении; за пределами Godot res://.
- Content.Client/UI/Screens/ — восемь макетов с именованными областями без фиктивных значений.
- Content.Client/UI/Workbench.tscn — самостоятельная сцена примерки, без подключения к серверу.

## Пакет графики

| Группа | Предпочтительный экспорт | Что подготовить |
| --- | --- | --- |
| Пергамент | PNG/WebP, 512–1024 px, alpha при неровных краях | Фон без текста; отметки сохраняемых краёв для nine-patch |
| Тёмные панели | PNG/WebP или StyleBoxFlat | Основная панель, боковая панель, HUD |
| Кнопки | PNG/WebP, 256×64 или вектор | normal, hover, pressed, disabled; отдельная рамка focus |
| Вкладки | PNG/WebP или StyleBox | обычная, выбранная, недоступная |
| Слоты | PNG/WebP, 128×128 | обычный/выбранный; рамка отдельно от предмета |
| Иконки | PNG/WebP 128×128 или 256×256; простые знаки SVG | Навигация, публичные навыки, категории вещей, состояния; без встроенных чисел/букв клавиш |
| Портреты | PNG/WebP 512×512 | Лицо в центральной безопасной области; круглая рамка отдельным файлом |
| Иллюстрации | PNG/WebP, примерно 1024×1536 | Если нужны конкретному NPC/Эхо; не заменяют внешний вид игрока |
| Карточки мест | PNG/WebP, примерно 768×432 | Изображение соответствующего региона/места; без надписей |
| Карта | Согласованные слои/тайлы региона | Географическая привязка к навигации; картинка случайного острова не используется |
| Шрифты | TTF/OTF + лицензия | Regular и Medium/Semibold, кириллица/латиница/цифры/знаки |
| Модели | GLB/glTF → отдельная visual-only Godot сцена | Модель/материалы/скелет/анимации; origin у ног, +Y вверх, примерно 1 единица = 1 м |

Размеры — рекомендации, а не ограничения импорта. Фактическую нарезку и поля согласуем по полученным файлам.
Исходные PSD/KRA/AI/Blend сохранять отдельно от runtime-экспортов. Для атласов приложить таблицу прямоугольников; в каталоге можно использовать AtlasTexture.

## Тема и nine-patch

В fantasy-skin.tres назначить Font/HeadingFont, при необходимости отредактировать цвета.
Для PaperPanel/DarkPanel/Button*/Slot*/Tab*/Input*/TooltipPanel/GaugeBackground и *Fill создать StyleBoxTexture, выбрать текстуру и указать texture margins (сохраняемые края) и content margins (отступ до текста).
В графике не запекать заголовки, значения, имена или описания. Подключены StyleBoxTexture из SVG-компонентов комплекта; при отсутствии ресурса сохраняется нейтральный StyleBox.
Не менять сам ресурс Theme из одного окна: готовые темы общие и кэшируются на запуск клиента.

## Ключи визуального каталога

Ключи чувствительны к регистру и не зависят от перевода, ID экземпляра или места в группе.

| Ключ | Текущее использование |
| --- | --- |
| skill.1, skill.2, skill.3, skill.5, skill.6 | Иконки существующих публичных навыков HUD; проверять фактический loadout |
| equipment.weapon / equipment.armor / equipment.unknown | Категории в рабочем инвентаре; конкретный definition ID пока не передаётся |
| preview.character | Visual-only модель только для workbench |
| preview.portrait | Портрет только для workbench |
| nav.character / nav.inventory / nav.map / nav.quests / nav.menu | Навигация HUD, боковая панель окон и меню |
| echo.<public-content-id> / npc.<public-content-id> / item.<public-content-id> | Будущее подключение конкретного контента после публичного ID-контракта |

Последняя строка — схема ключей, а не список скрытого контента. Сейчас нельзя связывать Мирy, NPC или предмет с изображением по локализованному имени, runtime EntityId/Handle или номеру активного слота.
Один UiArtEntry содержит Key, Texture и/или Model; Attribution хранит автора/лицензию. Пустой каталог допустим.
Дубликаты/пустые ключи/пустые записи диагностируются; отсутствие необязательной картинки не ломает экран.

## Модели

UiModelPreview имеет свой SubViewport/World3D, камеру, свет, поворот мышью и zoom.
SetVisual принимает только подготовленную визуальную сцену Node3D. В неё не включать NetworkClient, PlayerController, игровую физику, UI, звуки или gameplay-скрипты.
UiRoundFrame подготовлен для круглой маски миникарты; Content принимает существующую карту, рамка задаётся MinimapFrame.
Никакой автоматической загрузки моделей по серверной строке-пути.
SetMesh используется действующим окном персонажа: показывает текущую прототипную геометрию аватара.
После появления настоящего appearance/equipment renderer он должен передавать предпросмотру тот же визуальный состав через этот API. Сам UI не выбирает и не меняет экипировку.

## Макеты и подключения

UiScreenLayout.Slot(name) возвращает контейнер, в который presenter добавляет элементы с подтверждённым состоянием. ShowSlotGuides включает подписи только для разработки.

| Экран | Области |
| --- | --- |
| HUD | Minimap, Location, QuestTracker, Navigation, EchoPortraits, Messages, Resources, SkillBar, Interaction |
| Character | Header, Navigation, Equipment, Model, Statistics, Footer |
| Inventory | Header, Categories, Items, Currency, ItemDetails, Footer |
| WorldMap | Header, Legend, Map, LocationDetails, Footer |
| Journal / Guild | Header, Navigation, Entries, EntryDetails, Footer |
| Echo | Header, Portraits, Navigation, Model, EchoDetails, Footer |
| Dialogue | Header, SpeakerVisual, SpeakerName, Speech, Choices, Footer |

Наличие области не включает соответствующую игровую систему: Messages не является чатом, Guild — не реализация рангов Гильдии Авантюристов, EchoDetails не выдаёт фиктивное доверие.
Живые компоновки создают соответствующие presenters через UiComposition и UiWindow; восемь сцен UiScreenLayout остаются изолированной примерочной для художника, без сетевых подписок.

| Живой экран | Вход | Подключение |
| --- | --- | --- |
| HUD | После входа в мир | Миникарта, фактическая зона, HP/мана/выносливость/EXP, навыки и таймеры, активные Эхо, отслеживание поручения, сообщения мира/приглашения, группа |
| Персонаж | K | Текущая модель, серверные статы, черновик, preview/cancel/apply, навыки и слоты, переходы к экипировке/профессии |
| Инвентарь | I | Поиск, категории оружие/броня/материалы, монеты, состояние вещи, сравнение, equip/unequip с подтверждением |
| Эхо Прошлого | F3 или кнопка спутника | Известные активные Эхо, фактические имена/модели, дальность/радиус/cooldown; боевые команды T/Y/U |
| Гильдия авантюристов | G | Известные поручения из owner journal, состояние выполнения, награда EXP, переход к журналу и карте |
| Карта | M | Только открытые клетки навигации и известные места; масштаб, перемещение, легенда, локальная отметка только на открытой территории |
| Журнал | L | Текущие/завершённые поручения, известные слухи, прогресс материалов, EXP, включение/выключение трекера |
| Диалог | F2 рядом с NPC или клик по NPC | Модель собеседника из мира, имя, текст ответа, реальные варианты принятия/доставки |

Esc открывает меню; внутри окна закрывает его. Боковая навигация закрывает текущее окно через его политику закрытия и открывает выбранное. Одновременно открыто одно модальное окно. При открытии останавливается движение/автоатака; мир не ставится на паузу. Tab/Enter/Space работают в GUI, отпускание защитной клавиши обрабатывается. На выходе из мира подписки, маршруты и modal state очищаются.

Окна профессии P, ремесла C, обмена B, рынка J, группы N, гильдии игроков O, PvP V, хранителя H и памятки F1 используют ту же пергаментную оболочку и доступны из меню. Обмен и необратимая профессия сохраняют прежние серверные подтверждения.

Пределы текущих контрактов: нет игрового чата, рангов/репутации Гильдии Авантюристов, памяти/отношений Эхо и appearance IDs для персонального арта. Эти данные не подменяются демонстрационными значениями из SVG/HTML. Гильдия игроков и Гильдия Авантюристов разделены. Портреты в макете не становятся внешностью игрока; предпросмотры сейчас показывают прототипные модели из мира. Личная отметка карты хранится только до смены региона/выхода.

## Запуск

Открыть Content.Client/project.godot в Godot 4.7.1 .NET, собрать C#, открыть UI/Workbench.tscn и нажать F6.
Workbench не запускает сервер. Переключатели сверху показывают все восемь макетов; «Компоненты» — иконки, состояния кнопок и поле ввода. После замены ресурсов перезапустить сцену, поскольку тема и каталог кэшируются.
Для проверки рабочего инвентаря — I; персонажа — K; поручений — L; диалога — F2 рядом с NPC.
