# Character & Stats — отмена очков за достижения

Дата: 2026-10-20. Прямое решение пользователя имеет приоритет над прежними
§4.2–4.3 GDD 03 и планом C6.

> «выдача таких очков отмена, вместо них потом будет другая награда»
>
> «награда в виде очков характеристик отменяется»

Награда очками характеристик отменена и для shared, и для world_unique.
Новая выдача очков — 18 при создании и +5 за каждый следующий уровень;
на уровне 30 — 163 очка. Весь пул в одном стате даёт 173 без оборудования
и эффектов. Категории достижений не отменены; другая награда ещё не определена.

Предложенные +1/+3 за test_boss не одобрены. Их условия, winner policy,
tie-break, lifetime claim и получение двух наград не считаются принятыми.
Код выдачи не создавался, tables/migrations/claims C6 не добавлялись.
EXP, предметы, валюту или косметику вместо очков автоматически не назначали.

## Что изменено

- Gameplay contract отражает отмену.
- Снимок GDD содержит явную отмену над прежними пунктами; исходный текст
  §4.2/части §4.3 сохранён как история, а не действующее требование.
- Архитектура, CS10, план C6 и `.codex/plan.md` синхронизированы. Прежний
  этап очковых достижений снят с реализации. C7 для включённых систем доступен.
- В игровом UI предложений очков за достижения не было, менять сцены не требуется.
- `SavedStatAllocation.AchievementBonusPoints` отмечено как storage-only
  совместимость V1. В runtime нет операций, увеличивающих это поле;
  значения есть только в исторических test fixtures. Поле и согласованность
  старого ledger сохранены, destructive миграция/обнуление не выполнялись.
  Тест концентрации переименован как проверка legacy-документа, а не выдачи.

Server/Client/Shared boundaries, protocol v82, SQL schema 12, цены и EXP-награды
C5 не менялись. Рабочая `.data` не открывалась. Новая система наград достижений
ожидает отдельного content/reward решения.
