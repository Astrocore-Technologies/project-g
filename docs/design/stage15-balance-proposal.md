# Утверждённый временный баланс этапа 15

Утверждён пользователем 2026-10-08 в этом чате и реализован в server content (BalanceVersion 2). Числа временные; это не окончательный баланс. Без LUK и без реальных платежей.

- Эволюция: клинок переправы (+12 ATK) → улучшенный клинок (+18 ATK), цена 2 слитка и 1 дерево. Сохраняются UUID, заточка, текущая/максимальная прочность. Ветка одноразовая, без отката и повторного создания предмета.
- Заточка: +0…+5; каждый уровень +2 ATK. Каждая попытка стоит 1 слиток. Шансы переходов: 100%, 80%, 60%, 40%, 20%. Провал сохраняет уровень, уменьшает максимальную прочность на 10, текущую ограничивает новым максимумом; максимум 0 уничтожает предмет. Ремонт не восстанавливает потерянный максимум. Server RNG и результат сохраняются один раз; повтор не бросает снова.
- Локальный рынок: обычные неснаряжённые предметы за целое положительное число игровых монет; без комиссии. Один seller ≤2 listings, регион ≤8 активных listings. Закрытый escrow, автоматического истечения нет; отмена возвращает тот же экземпляр. Продажа создаёт credit продавцу, выдача монет только через идемпотентное получение выручки. Переполнение inventory/wallet/credits отклоняет операцию целиком.
- Начальные монеты: 0. NPC покупает руду за 1 монету/единицу; кошелёк ограничен 1 000 000. Это только тестовый источник валюты, не постоянная экономика.
- Восстановление ресурса: через 10 минут после полного истощения вернуть исходные 16 дерева/24 руды. Deadline сохраняется; restart не меняет срок. При ненулевом запасе refill не срабатывает.

Все операции показывают цену/риск до отдельного подтверждения; сервер проверяет ownership, quote, revision, proximity, lock и replay. Числа вынесены в validated server content и могут быть заменены без смены правил протокола.
