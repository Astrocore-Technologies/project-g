# Этап 17 — предложение правил групп и гильдий

Статус: Approved для прототипа, 2026-10-08. Пользователь утвердил весь пакет и разрешил реализацию сообщением «го». Временные коэффициенты прототипа не являются постоянным дизайном.

## Уже принято

Обычная группа до 6 игроков, расширенная до 20. Нет обязательной Holy Trinity и autoscale босса по размеру группы. Сервер авторитетен; один логический мир, без персональных копий локации. Эхо сохраняют владельца. Правила этапа 16 действуют: city no PvP, tag120с, equipped unbound drop, tagged pickup5с, expiry30мин без возврата.

## Утверждённый пакет

| Область | Временное правило |
| --- | --- |
| Членство группы | Один персонаж — одна группа. Создание обычной группы возможно одному игроку. Лидер приглашает online персонажа через выбор видимого игрока; принятие добровольное, приглашение30с. Приглашение не резервирует место; полная/изменившаяся группа отклоняет acceptance без частичного вступления. |
| Размер | Лидер явно переключает 6→20. 20→6 разрешено только при составе ≤6. Расширенная группа не создаёт бонусов/штрафов к характеристикам и наградам. Подгруппы/назначаемые combat roles отложены. |
| Управление | Лидер приглашает, исключает, меняет формат и передаёт лидерство участнику; каждый может выйти. Последний выход закрывает группу. Нет автоперемещения/автоподхода к участнику. |
| Disconnect | Членство сохраняется при disconnect/death/restart. Offline участник занимает слот, HP/координаты не выдаются как актуальные. После120с отсутствия лидера online участник с самым ранним join ordinal становится лидером; если online нет, прежний лидер сохраняется. После рестарта льготное окно начинается заново. Возвращение прежнего лидера не отбирает лидерство. |
| PvP внутри группы | Урон участнику своей группы запрещён для melee/projectile/AoE/Echo; иммунитет проверяется на impact. Не снимает tag/aggressor/PK и не защищает от посторонних. Для принятия/вступления/выхода/исключения/передачи лидерства/смены формата затронутые участники должны быть вне PvP-tag и aggressor window; боевые эффекты/каст также блокируют переход. Приглашение само не меняет combat policy. |
| Гильдия и PvP | Членство гильдии само не даёт PvP-иммунитет. На участников разных групп распространяется stage16 policy. Guild/faction wars и дипломатия отложены. |
| EXP | Существующий личный EXP за подтверждённые PvE-действия/исследование/крафт остаётся личным. Нет party bonus, автоматического деления или бесплатного EXP стоящему рядом. Группа помогает играть вместе, но не вводит новый farming loop. Общие kill/boss/event rewards требуют отдельного contribution design и не придумываются в этапе17. |
| Лут | Autoloot/round-robin/need-greed/master loot не вводятся. Seed/PvP world items подбираются вручную по прежним проверкам, один получатель; party/guild не резервирует вещь. Для PvP-вещи каждому подбирающему нужен свой active tag и полный5с канал. Передать добычу можно существующим добровольным обменом. Boss loot/contribution остаётся unresolved. |
| Видимость | Состав/online/dead/HP/регион/позиция известны своей группе. Актуальные HP/позиция — только online участникам текущего региона; без раскрытия fog/secrets/профессий. Social marker не создаёт дальний player/Echo spawn или дополнительные world snapshots. Гильдия видит состав/роль/online, без дальних координат/HP. |
| Гильдия | Один персонаж — одна гильдия, одновременно можно состоять в любой группе. Создание бесплатно, без нового currency sink. Prototype cap32 персонажа, включая offline. Имя3–24 Unicode characters, до96 UTF-8 bytes после нормализации; уникально среди активных гильдий. Rename/герб/тег/персонажные имена отложены. |
| Роли | Единственный Leader; Officer приглашает и исключает только Member; Member не меняет состав/права. Только Leader назначает/снимает Officer и передаёт Leadership. Officer не может исключить другого Officer/Leader или повышать себя. |
| Смена главы | Guild Leader не переизбирается автоматически при offline. Передача существующему online члену требует его явного принятия в течение30с. Leader выходит после успешной передачи; единственный последний участник может отдельно подтвердить закрытие гильдии. Самостоятельный выход Member/Officer разрешён. |
| Persistence | Group/guild membership/roles/leadership переживают restart. Invitations/предложения передачи лидерства ephemeral и аннулируются при disconnect/перезапуске/изменении ревизии. Повтор команды не создаёт второе членство/гильдию. |
| Границы | До64 групп и32 гильдий в prototype realm, серверные configurable budgets. Отказ при заполнении явный. Нет чата, банка, guild currency, налогов, владения миром, поиска групп, календаря, offline приглашений, account recovery, cross-region presence или production identity. |

## Статус реализации

Пакет реализуется в этапе17. Permanent balance и production/cross-region authority не приняты. Утверждение правил не заменяет домашнюю визуальную приёмку Godot.
