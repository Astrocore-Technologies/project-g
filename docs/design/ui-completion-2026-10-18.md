# Завершение UI/UX по концептам

Объём: все существующие пользовательские окна клиента, их состояния и HUD-компоненты. Основа — утверждённые изображения в `art-source/ui/rework-2026-10-17/`, включая уточнение ресурсов `05-player-resources-reference.png`. Новый gameplay, модель мира и содержимое неизвестных профессий не добавляются.

Границы: Content.Client scenes/resources/presenters и тестовые адаптеры. Server/Shared/wire protocol/persistence не меняются. Динамические списки инстанцируют общие карточки; постоянная компоновка сохраняется в сценах. Скрытые preview отключены, карты остаются ограниченными по размеру и публичным данным. Godot Mobile renderer используется для PC; Mobile input вне объёма.

Порядок: (1) общий UI kit и типографика, (2) ремесло/рынок/обмен, (3) группа/гильдия/PvP/хранитель, (4) журнал боя/смерть/памятка/эмоции/настройки, (5) художественное согласование основных окон, (6) сборка и реальные MCP-прогоны, (7) скриншоты и сведения о настройке.

Проверка: отдельные сервер/БД/identity для действующих команд; основные маршруты при 1280×720 и 1920×1080, длинные подписи и scroll, Escape/focus, отсутствие gameplay input через модальные окна, пустые/загрузка/pending/error/confirmation. Состояния, не достижимые в выбранном регионе, проверяются в другом подходящем тестовом регионе или явно обозначенном offline адаптере той же рабочей сцены. Прототипные капсулы мира сохраняются. Финальный отчёт обязан различать реальные серверные сценарии и fixture-кадры.

Статус: перенос всех существующих пользовательских окон в рабочие редактируемые сцены завершён. Дальнейшая расширенная отладка остановлена по просьбе пользователя. Это завершение переноса UI; не утверждение о готовности всех серверных игровых систем.

## Рабочие сцены

Все пути ниже — внутри `Content.Client/UI/Screens/`.

| Интерфейс | Сцена |

| Персонаж: облик, характеристики, навыки, профессия | `CharacterView.tscn` |
| Инвентарь | `InventoryView.tscn` |

| Эхо / диалог / профессия | `EchoView.tscn`, `DialogueView.tscn`, `ProfessionView.tscn` |
| Ремесло, сбор, ремонт | `CraftingView.tscn` |
| Кузница, рынок, скупщик, подтверждение цены | `EconomyView.tscn` |
| Обмен, приглашение, предложения сторон | `TradeView.tscn` |
| Группа и гильдия игроков | `SocialView.tscn` |
| PvP / хранитель | `PvpView.tscn`, `KeeperView.tscn` |
| Журнал боя / смерть | `CombatJournalView.tscn`, `DeathView.tscn` |

## Настройка и автономный просмотр

Открыть `Content.Client/UI/Workbench.tscn`, запустить F6 и выбрать рабочую сцену. Workbench больше не строит отдельные макеты. Старые `Character.tscn`, `Inventory.tscn` и аналогичные пути инстанцируют соответствующий рабочий View. Главное меню отдельно: `Tests/UI/MainMenuPreview.tscn`.

Общий стиль — `UI/Theme/rework-theme.tres`; HUD-ресурсы — `player-resources.tres`, меню — `menu-theme.tres`. Шрифты Noto Sans/Serif поставляются с OFL и источниками в `Assets/UI/Fonts/Noto/`. Декоративный лесной фон и его происхождение: `art-source/ui/rework-2026-10-17/completion-assets.json`.

## Фактическая проверка

- `dotnet build Game.slnx --no-restore -m:1`: успешно, 0 ошибок; 4 прежних предупреждения NU1903/NU1900. Последующие изменения клиентских сцен/презентеров также собирались отдельно без ошибок.
- `UiReworkSmoke` через MCP: 18 живых маршрутов, вкладки, границы окон, блокировка ввода, поиск, Escape, центрирование миникарты у четырёх границ, explored-only pin, teardown; 1280×720 и 1920×1080 — успешно.
- `UiReworkInventorySmoke`: реальное надевание предмета с подтверждением сервера, закрытие и очистка — успешно.
- `UiReworkHudSmoke`: портрет, ресурсы, черновик характеристик, отмена и атомарное применение с сервером, resize — успешно.
- `UiFoundationSmoke`: реальные рабочие сцены offline, каталог, изолированный viewport, keyboard activation, focus, Escape и modal cleanup — успешно. После прогона в список Workbench добавлено также меню паузы.
- `LifeSmoke`: DTO fixtures смерти/таймеров/возрождения, полученных Эхо и отказа, пассивных навыков — успешно.
- `UiStateSmoke`: явно изолированные DTO fixtures ожидания и необратимого подтверждения профессии, checkbox, отмена и очистка — успешно.
- `dotnet test Content.Tests/Content.Tests.csproj --no-build --no-restore --filter FullyQualifiedName~Trade`: 11/11 успешно. Первый sandbox-запуск был прерван из-за недоступного testhost-соединения; засчитан повтор с доступом к localhost.

**Не закрытая проверка:** повторный сквозной Godot UI-прогон обмена остановился по timeout ожидания приглашения. Перенос `TradeView` завершён; полный повторный сетевой сценарий не засчитан. Добавлен выход из бесконечного pending с понятным сообщением. Новый адаптер `UiReworkQuestSmoke` подготовлен, но до остановки задачи не прогонялся. Не выдавать эти сценарии за пройденные.

Реальные рендеры: `.artifacts/ui-final-2026-10-18/live/` (окна и вкладки в двух разрешениях), `workflows/` (серверные состояния, не доказательство полного успешного прогона), `fixtures/` (чётко отделённые DTO fixtures). JSON результатов — `results/`, отдельные stdout/stderr сохранены рядом. Основные игровые снимки через MCP — `user://screenshots/ui-final-*.png`.

Портрет и облик в UI — иллюстрации; реальная экипировка показывается в серверных слотах. В прототипном инвентаре остаются настоящие 3 типа экипировки и вместимость 8. Карты используют реальную публичную геометрию и серверное исследование; декоративный арт не подменяет географию.
