# Этап 16 — предложение правил PvP, смерти и репутации

Статус: утверждён пользователем 2026-10-08 с правками ниже. Числа — временный баланс прототипа; этап 16 реализован как прототип, приёмка ожидается.

## Принятая основа

Manual action combat, безопасные области, working model PvP-tag, PK/reputation. PvE-смерть отнимает EXP без потери gear; PvP с active tag допускает gear drop. Уровень не теряется. Нет autoloot; вещи существуют в мире и доступны третьим лицам по согласованным правам. Echo участвуют в бою через ответственность владельца. Fast travel не добавляется.

## Утверждённый пакет для прототипа

| Решение | Принятое правило |
| --- | --- |
| Мирная игра | По умолчанию PvP выключен. Прямая атака, projectile, AoE и Echo не повреждают мирного игрока без отдельного осознанного режима нападения. |
| Добровольный PvP | Игрок явно включает PvP вне защищённой области, сразу получает тег на 120 секунд. Отключение разрешено после окончания боевого таймера; переключение не сбрасывает ответственность за выпущенные эффекты. |
| PvP-tag | Любое разрешённое враждебное PvP-попадание помечает обе стороны на 120 секунд. Каждое следующее попадание обновляет срок. Попытка сознательного нападения также ставит тег нападающему, даже при промахе, но не жертве. |
| Safe zones | Город защищён: проверяем позиции источника и цели при попадании. Нельзя бить из города или внутрь него. Вход в город разрешён с боевым тегом; внутри города PvP запрещён. Респаун в городе разрешён по отдельному правилу ниже. |
| Преступное нападение | Отдельное явное включение режима «Нападение на мирных» с предупреждением о PK, репутации и риске вещей. Первое допустимое нападение делает нападающего агрессором на 10 минут. Попытки в safe zone не причиняют вреда и не начисляют PK. |
| Самооборона | Атаковать активного агрессора можно без преступного штрафа; защитник получает combat tag. Это правило распространяется на третьих лиц. Нападение на добровольно PvP-включённого персонажа или игрока с активным тегом также законно. |
| Репутация / PK | Стартовая репутация 0, диапазон −1000…1000. Преступное нападение: −10 один раз на пару персонажей в 10-минутном эпизоде. Убийство мирной жертвы в таком эпизоде: дополнительно −100 и PK +1, один раз на death ID. Преступность не очищается отключением режима, смертью или переподключением. Положительная репутация, награды за охоту и искупление отложены. |
| Источник смерти | Сохраняем виновника последнего смертельного урона. Если NPC добил жертву в течение 30 секунд после PvP-урона, применяем PvP-риск и отмечаем смешанную причину; недавний виновник может получить PK за мирную жертву. Один только добровольный переключатель без боя не превращает PvE-смерть в PvP. |
| EXP | PvE: потеря floor(5% текущего EXP внутри уровня); PvP/смешанная смерть: floor(10%). Не отнимаем уровень, полученные stat points, навыки и профессию. Минимум EXP 0. |
| Gear drop | PvE: 0 вещей. PvP/смешанная смерть: максимум один непривязанный предмет только из экипированного, включая legendary без bound. Сервер выбирает равномерно из допустимых экземпляров один раз; если таких нет, дропа нет. Материалы, деньги, escrow рынка и предложения обмена сами по себе не являются отдельным источником дропа. Предмет в незафиксированном обмене остаётся inventory владельца после отмены и может участвовать в выборе. |
| Качество экземпляра | UUID, эволюция, enhancement, current/maximum/revision и история ownership сохраняются. После переноса вещь unequipped. На смерти нет дополнительного снижения прочности. |
| Bound | Привязанные к персонажу вещи не выпадают и не могут быть подобраны другим владельцем. В прототипе вводится явная серверная drop policy; текущие обычные crafted/gear items остаются обычными. |
| Legendary | Непривязанная legendary может выпасть на общих основаниях; bound защищает её от дропа. |
| Права на лут | Любой живой игрок может начать подбор сразу. Для начала и завершения подбора требуется активный PvP-тег. Подбор сам не включает PvP. Подбор PvP-лута длится 5 секунд и прерывается движением, действием, уроном, смертью или disconnect. Предмет не резервируется эксклюзивно; завершить перенос может один получатель. |
| Срок лута | Через 30 минут от смерти предмет уничтожается, UUID становится terminal. Возврата владельцу нет. |
| Переполненный мир | Если общий ground budget или bounded death-loot storage исчерпан, вещь остаётся экипированной у погибшего; DropSkippedCapacity записывается в receipt/audit. Смерть и EXP/репутация всё равно фиксируются. Возврат/хранилище не вводятся. |
| Возрождение | Только явное подтверждение игрока: через 15 секунд после PvE-смерти / 60 секунд после PvP или смешанной смерти, у фиксированной городской точки. HP 100%, mana 50%; оплаченные cooldown не сбрасываются. Смерть остаётся при reconnect. Доставка погибшего к точке — исключение смерти, не travel-функция. |
| После возрождения | До первого враждебного действия или 10 секунд — защита от PvP; сознательное нападение снимает её. Долги PK/репутация и добровольный PvP-режим сохраняются; combat tag очищается именно при принятом respawn. Safe-zone правила остаются в силе. |
| Echo | Весь PvP-урон Echo относится к владельцу. Они не обходят tag/safe zone/самооборону. После смерти владельца прекращают атаки и активные эффекты; экземпляры Echo не выпадают и не удаляются. При respawn следуют за владельцем, cooldown сохраняются. |
| Logout в бою | При разрыве соединения tagged-персонаж остаётся в simulation до 30 секунд без новых команд; ownership session удерживается до завершения checkpoint. Повторное подключение забирает ту же сущность. Смерть за это время сохраняется. Это временное ограничение combat logging, а не полноценная production anti-abuse система. |
| Restart | Серверный рестарт сохраняет тег/эпизоды/death/loot/deadline. Времена UTC не уменьшаются из-за reconnect. Убийство offline-персонажа во время остановки процесса не симулируется. |

## Границы прототипа

Один регион, одна safe zone, одна точка respawn; без faction wars, bounty payouts, criminal settlements, prison, guild rights, party immunity, healing-assist attribution и участия в наградах PvP. Нет EXP/монет за убийство игроков: исключаем новый farming loop до отдельного решения.

Criminal intent применяется явно на сервере и в UI, а не через случайную AoE. При атаке нескольких игроков разрешение и преступность проверяются для каждой цели; один cast не даёт бесконечные штрафы за несколько тиков эффекта. Бюджет эпизодов ограничен, при заполнении новые преступные попадания отклоняются; оплаченная способность может промахнуться. Подробные attribution/TTL/budget правила — в архитектуре.

## Решение пользователя

«ГО» с явными изменениями: legendary без bound может выпасть; подбор доступен сразу, но в PvP длится 5 секунд; возврата нет, через 30 минут уничтожение; дроп только экипированного; вход в город разрешён, внутри PvP запрещён. Остальные строки пакета утверждены как временные правила. Повторное подтверждение для реализации не требуется.

Дополнение пользователя: подбор такой экипировки разрешён только при активном PvP-теге, включая завершение пятисекундного канала.
