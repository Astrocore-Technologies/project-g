# Малая крытая трибуна Линвеля

Новый оригинальный ассет 2026-10-20. Сначала создан `arena-stand-concept.png`
встроенным ImageGen; полный запрос в `concept-prompt.txt`. Затем модель
собрана в Blender через MCP. Старые модели библиотеки не пересоздавались.

- `arena_covered_stand-large.blend` — текущий редактируемый исходник, **14 × 7 × 4.58 м**;
  высота ступеней и сидений сохранена. `arena_covered_stand.blend` — прежняя
  меньшая версия, оставленная для истории. Активная сцена
  `Linvel_TrainingAsset`, коллекция `LV_arena_covered_stand`.
- `exports/arena_covered_stand.glb` — только ассет без студии, 2872 треугольника.
- `previews/arena_covered_stand.png` — реальный рендер Blender.
- `previews/arena_covered_stand-large.png` — текущая увеличенная версия.
- `reports/arena_covered_stand.json` — размеры, части, 36 проверенных соединений.
- `reports/glb-validation.json` — проверка экспортированного бинарного файла.

Геометрия в метрах, root у земли; GLB Y-up, фасад +Z. Пять mesh-групп
разделяют основание, дерево, сиденья, крышу и ткань. Локальные части доступны
через атрибут `LinvelPartID`. Прежний оригинальный painted atlas библиотеки
упакован в `.blend` и GLB; внешние модели и сторонние текстуры не использованы.
Отдельная лицензия этим новым файлам не назначалась.

`tools/build_arena_stand.py` — авторинг только через Blender MCP; отказывается
заменять существующий исходник. Для изменений работай с `.blend` и экспортируй
его коллекцию с `use_active_scene=True`, без повторной генерации.

`tools/enlarge_arena_stand.py` — выполненная через MCP правка размеров существующей
геометрии по уточнению пользователя. Масштаб запечён в mesh; root и объекты имеют
scale=1. Исходный 2D-концепт одобрен пользователем; нового концепта не требовалось.
