# Референсы города Линвеля

Пользователь предоставил эти материалы 2026-10-11 при проектировании
функциональной схемы котловины и подтвердил арт-лист как основу облика города.

- `linvel-town-art-sheet.png` — исходное изображение пользователя:
  `codex-clipboard-a91e9480-624d-48d7-abec-4e5c3b1d30d2.png`.
- `linvel-lore-user-20261011.txt` — предоставленный вместе с изображением текст
  «Линвель и земли между морем и горами», сохранён без редакционных изменений.
- `linvel-visual-user-20261011.txt` — последнее уточнение пользователя о
  Stylized Hand-Painted Anime 3D, сохранённое из вложения при начале реализации.

Арт-лист задаёт композицию террас, гавани, площади, Гильдии, жилых кварталов
и двора Дорна. Направления моря, гор и выхода определяются лором; вид изображения
можно повернуть при переносе композиции в план. Игровые правила задаются
[паспортом альфы](../../../docs/design/linvel-alpha-passport.md) и
[gameplay contract](../../../docs/design/gameplay-contract.md).

Эти файлы — материалы для внутреннего проектирования. Они не являются игровыми
текстурами, готовой сценой или новой лицензией на ассеты.
