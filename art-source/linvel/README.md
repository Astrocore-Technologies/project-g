# Объекты Линвеля

50 отдельных статических моделей по новому арт-листу пользователя. Геометрия и живописный текстурный атлас созданы в Blender 5.2.2 через официальный Blender Lab MCP. Общий исходник содержит редактируемые mesh-объекты; размещение города не выполнялось.

## Где смотреть и редактировать

- `linvel_asset_library.blend` — основной исходник. Сцена `Linvel_AssetLibrary` содержит коллекции `LV_<asset_id>`. Сцена `Linvel_Catalog` — только обзор набора.
- `exports/<asset_id>.glb` — по одному самостоятельному GLB на модель, с PNG внутри файла.
- `previews/<asset_id>.png` — отдельные ракурсы с высокой камеры. `linvel_catalog.png` — обзор с подписями.
- `textures/linvel_painted_atlas.png` — общий атлас 2048 × 2048.
- `catalog.json` — названия, размеры, категории, число треугольников и пути к файлам.

В исходнике включай нужную коллекцию в Outliner через флаг исключения из View Layer. Части объединены по назначению: `Structure`, `Roof`, `Joinery`, `Glazing`, `Cloth`, `Metalwork`, `Foliage`. Отдельные черепицы, балки и детали остаются mesh-островами, доступными для ручной правки. Атрибут граней `LinvelPartID` сопоставлен с именами деталей в `reports/<asset_id>.json`.

Все 50 коллекций отмечены как Assets и доступны в Asset Browser → Current File. У них есть категории, тег Linvel и русское описание. Памятка также сохранена внутри `.blend` как текст `Linvel_README`.

Чтобы перенести одну модель в другой Blender-файл, используй File → Append → этот `.blend` → Collection → `LV_<asset_id>`. Корневой Empty задаёт точку размещения. Исходник содержит упакованный атлас.

## Импорт в Godot

GLB использует метры, Y-up, единичный scale и корень в точке размещения. Передняя сторона после преобразования осей направлена по +Z. Для лодок и причалов корень задаёт уровень воды, поэтому часть геометрии находится ниже нуля. Здания и предметы имеют наземный корень.

Перенеси необходимые GLB в папку ассетов Godot и добавляй их как сцены. В Import оставь Root Scale = 1 и Generate LODs = On. В проверочном импорте Godot также создал shadow meshes. Навигацию и простые коллизии назначай при размещении; декоративные mesh-объекты сами по себе физические тела не создают.

Материалы GLB — переносимые Principled/PBR с базовым цветом из атласа. Для аниме-освещения приложен `godot/linvel_cel.gdshader`: создай ShaderMaterial, назначь этот shader и общий PNG в параметр `albedo_texture`, затем используй материал на нужных MeshInstance3D. Один общий материал/атлас позволяет переиспользовать текстуру между экземплярами. Встроенные PNG делают GLB самостоятельными, но массовую загрузку разных моделей лучше настроить на общий атлас.

Модели статические: здания оформлены снаружи, парус и знамёна имеют заданную форму, струи фонтана представлены геометрией. Анимация ветра, вода, интерактивные двери и внутренние помещения относятся к следующему этапу работы с локацией.

## Проверка

- `reports/blender-audit.json` — проверка точек размещения, transforms, UV, материалов, конечных координат и площадей граней: 50 моделей, ошибок нет.
- `reports/glb-validation.json` — чтение фактических бинарных GLB: геометрия, normals, UV, материалы и встроенные PNG; служебных объектов и анимаций в экспорте нет.
- `reports/godot-import-validation.json` — 50 сцен импортированы и инстанцированы в Godot 4.7.1; проверены vertex/normal/UV arrays и текстуры материалов.
- `previews/godot_adventurers_guild.png` — захват реального Godot Mobile renderer / Vulkan с приложенным cel shader, камерой 45°.

Проверки Godot запускались в изолированном проекте `.artifacts/linvel-godot-check`; игровые сцены, сервер, протокол и gameplay-код не изменялись. Производительность заселённого города этой проверкой не измерялась. Самая подробная модель — цветущее дерево, около 102 тысяч треугольников в исходном качестве; в игре используй LOD и подходящую дальность отображения.

`tools/linvel_builder.py` — вспомогательный исходник авторинга для исполнения внутри Blender MCP. Основной редактируемый результат — `.blend`; экспорт берёт существующую геометрию. Повторная генерация не требуется для использования или редактирования моделей. `tools/verify_glb.py` только читает экспорты и пишет отчёт.

Референс — арт-лист, предоставленный пользователем (`codex-clipboard-db2c4496-7746-414c-bef3-b0f40036da7b.png`). Сторонние модели и текстуры не использовались; отдельная лицензия новым файлам не назначалась.
