# Лисьи холмы — исходники моделей

Библиотека создана в Blender через MCP для Project G. Земля и проходимые склоны хранятся отдельно в Godot Terrain3D.

`fox_asset_library.blend` содержит отдельную сцену `FoxHills_Asset_Library` и 12 моделей: сторожевой пост, навес пастуха, разрушенное хозяйство, ворота, указатель, два каменных выхода, валун, два вида вереска, кустарник и сухая трава. Всего 55 120 треугольников в уникальной библиотеке. Полный перечень и размеры — в `catalog.json`, отчёты по каждому объекту — в `reports/`.

Модели находятся в собственных коллекциях; после экспорта они скрыты. Для ручной работы включи нужную коллекцию и видимость объектов. Пост имеет каменное основание, штукатурку, балки, оконные рамы, ставни, дверь, отдельную черепицу, трубу и вымпел. Навес открытый; у разрушенного дома остались стены, труба, балки и обломки.

`textures/fox_painted_atlas.png` — собственный рисованный атлас 2048 × 2048. UV подготовлены под его участки. Материалы GLB используют обычные совместимые с glTF параметры. Обработка света в игре задаётся Godot-материалом `painted_hills.tres`; она не зависит от Blender shader nodes.

Экспортированные GLB находятся в `Content.Client/Assets/World/Linvel/FoxHills/`. У моделей единичные трансформы и опорная точка у земли. Проверены конечные координаты, нормали, UV, индексы, отсутствие вырожденных треугольников и соединение основных конструктивных частей.

`tools/build_fox_assets.py` — инструмент первоначального производства, выполненный внутри Blender через MCP. Он использует собственные общие функции из `art-source/linvel/tools/linvel_builder.py`. Его не нужно запускать для изменения размещений в Godot. После ручного изменения моделей не перезапускай первоначальную сборку поверх правок: экспортируй изменённый объект отдельно и явно обнови его игровой ресурс.

Редактирование сцены, рельефа и проверки описаны в [техническом паспорте](../../../docs/development/linvel-fox-hills.md).
