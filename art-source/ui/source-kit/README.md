# Используемые исходники прежнего UI-комплекта

Здесь сохранена часть предоставленного пользователем `Project_G_UI_Source_Kit`,
которая нужна текущим игровым ресурсам. Это библиотека графики, а не старый
интерфейс для подключения к игре.

- `icons/` — 40 исходных белых SVG-вариантов из `godot/icons` прежнего комплекта.
  Они используются напрямую и через действующий каталог `art-catalog.tres`.
- `components/` — 11 редактируемых SVG панелей, кнопок и слотов, используемых
  действующей skin и темой меню. Экспорт удаляет демонстрационный текст и рисунки.
- `tokens.json` — исходная палитра для справки о происхождении. Текущие цвета,
  шрифты и компоновка редактируются в `Content.Client/UI`, а не генерируются из неё.
- `ASSET_PROVENANCE.md` — оригинальные сведения о происхождении, сохранённые
  без изменений. Пути к демо/иллюстрациям внутри этого исторического документа
  относятся к полному исходному комплекту в архиве.

Проверка соответствия SVG без записи:

```powershell
python tools/import-ui-source-kit.py --check
```

Повторный экспорт SVG после ручного редактирования исходников:

```powershell
python tools/import-ui-source-kit.py
```

Команды работают из корня репозитория; сам скрипт не зависит от текущей папки.
Игровые пути `Content.Client/Assets/UI/Icons/SourceKit` и `Textures/SourceKit`
сохранены. Существующие темы, каталоги и `.import` скрипт не перезаписывает.

Полная исходная поставка (156 файлов, включая HTML-превью, старые макеты,
демонстрационные данные/код и иллюстрации) сохранена локально в
`.artifacts/archive/ui-source-kit-20261020/`. Архив исключён из Git; прежняя
поставка также остаётся в истории Git. В активную папку перенесены только
нужные исходники и сведения об их происхождении.
