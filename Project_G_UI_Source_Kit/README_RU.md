# Project G — «Хроники странника»
## Исходники UI/UX для ПК · версия 0.1

Это редактируемая пересборка интерфейса по обсуждённому визуальному направлению: светлый пергамент, латунные акценты, сине-серые панели, яркое stylized-окружение. Это **не извлечённые слои исходной генерации** и не пиксельная копия коллажа.

### Начать здесь

Откройте **`Preview.html`** в обычном настольном браузере. Это самодостаточный кликабельный прототип: интернет, сервер, npm, аккаунт и установка библиотек не нужны. Никаких данных наружу он не отправляет. Состояние демонстрации сбрасывается после перезагрузки.

Для работы с исходным кодом используется `prototype/index.html` вместе с соседними CSS/JS и папкой `assets`. При ограничениях браузера на локальные файлы можно запустить из корня `python -m http.server 8000` и открыть `http://localhost:8000/prototype/`.

### Восемь экранов

1. **HUD исследования:** миникарта, безопасная зона отдельно от PvP-тега, группа, чат, 8 навыков, 3 команды Эхо.
2. **Персонаж:** модель/иллюстрация, экипировка, 6 базовых характеристик, производные параметры, источники модификаторов.
3. **Инвентарь:** поиск, категории, выбор предмета, сравнение, экипировка, защита от случайной продажи и информация о риске.
4. **Эхо Прошлого:** известная коллекция, личность, состояние, связь, воспоминания, команды отряду.
5. **Гильдия Авантюристов:** общий ранг, местное доверие, поручения, достоверность сведений и условия договора.
6. **Карта:** известные места, туман исследования, приблизительные слухи, личная отметка. Без fast travel.
7. **Журнал:** задачи, источники сведений, слухи, подтверждённые открытия, закрепление поручения.
8. **Диалог:** NPC, выбор реплики и добровольная регистрация в Гильдии.

### Что действительно редактируется

Панели, границы, кнопки, иконки, подписи и векторная карта — отдельные SVG-объекты, сгруппированные по смыслу. В SVG сохранены `<text>`, а не только контуры букв. Их можно редактировать в подходящем векторном редакторе или непосредственно в XML.

Фон мира и портреты — отдельные **растровые** объекты. Они встроены в полноэкранные SVG для переносимости, но их оригиналы лежат в `assets/art/`. Это не 3D-модели и не готовый высокодетализированный арт для релиза. Силуэты некоторых персонажей вручную отделены от коллажа; у них ограниченное исходное разрешение.

Нативный `.fig`, Auto Layout-компоненты Figma, PSD со слоями и собственный шрифт в комплект не входят. Импорт SVG в другой редактор может менять структуру текста и групп; совместимость конкретного редактора здесь не проверялась.

### Что работает в HTML-прототипе

Переходы между экранами мышью и горячими клавишами; поиск и фильтрация предметов; локальный выбор оружия и сравнение; защита от продажи; сведения о легендарном предмете; выбор поручения и подтверждение контракта; предупреждение о недостаточном ранге; закрепление задачи; показ/скрытие слоёв карты; добавление заметки в фиксированную демонстрационную точку; отзыв Эхо; статические диалоги; модальные окна с клавиатурным фокусом.

Горячие клавиши: `C` — персонаж, `B` — инвентарь, `N` — Эхо, `J` — журнал, `M` — карта, `Esc` — закрыть. В HUD `Q W E R A S D F` показывают демонстрацию перезарядки, `1 2 3` — команды Эхо. **Tab в браузере оставлен для доступной навигации по интерфейсу**, а не перехвачен под боевой блок.

Это не симулятор MMORPG. Перемещение, бой, сетевой чат, экономика, платежи, искусственный интеллект, сохранение персонажа и настоящие награды не реализованы. Цифры, имена, награды и свойства предметов — примеры, а не новый игровой баланс.

### Нативный Godot-starter

Импортируйте **`godot/project.godot`** как отдельный проект. Внутри: `Theme`, `StyleBoxFlat`, настоящие `Control`/`Button`/`Label`/`LineEdit`, HUD, инвентарь, панель Гильдии и три базовые компонентные сцены. Это не полноэкранные картинки вместо интерфейса.

Нативный starter охватывает **три экрана**, а не все восемь. Для остальных подготовлены SVG и браузерный UX-прототип. GDScript здесь используется только для автономной демонстрации; перенос в ваш C#-клиент описан в `docs/GODOT_INTEGRATION.md`.

**Проверка:** HTML-прототип прошёл 39 автоматических проверок в Chromium; SVG и ссылки ресурсов проверены статически. Godot в среде подготовки не был доступен для запуска: нативные сцены и GDScript **не прошли runtime-проверку движком**. Перед интеграцией нужен импорт в используемую версию Godot и проверка в редакторе.

### Пересборка

Нужны Python 3.10+ и Pillow. Файлы шрифтов скачивать или переносить из пакета не требуется.

```bash
python -m pip install -r requirements.txt
python src/build_design.py
python src/build_components.py
python src/build_godot.py
python src/build_standalone.py
python tests/validate_sources.py
```

Основные цвета/шрифтовые семейства меняются в `design/tokens.json`, геометрия экранов — в `src/build_design.py`, поведение — в `prototype/app.js`, стили браузерных диалогов — в `prototype/styles.css`. Ручные правки готовых SVG следует сохранить отдельно: генератор пересоздаёт файлы экранов. Заменённые файлы иллюстраций в `assets/art/` не перезаписываются автоматически.
