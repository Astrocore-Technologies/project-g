# Карта редактирования

## Макеты и слои

Каждый SVG-экран имеет `viewBox="0 0 1920 1080"`. Панели и группы подписаны через `inkscape:label`, интерактивные группы — через `data-action`. Шрифты не вложены. Исходные текстовые строки лежат в `<text>` и не требуют OCR.

`design/screens` удобно использовать как дизайн-исходники; `prototype/screens.js` генерируется из той же геометрии для браузера. Не редактируйте сгенерированный screens.js как единственный источник: следующий запуск генератора его заменит.

### Основные точки изменений

| Изменение | Файл / место |
|---|---|
| Палитра | `design/tokens.json`, ключ `colors` |
| Семейства шрифтов | `design/tokens.json`, `typography.body` и `typography.heading` |
| Размеры и расположение объектов | `src/build_design.py`, функции `hud`, `character`, `inventory` и т. д. |
| Форма собственных иконок | Словарь `ICONS` в `src/build_design.py` |
| Отдельная кнопка/панель | `src/build_components.py` |
| Сценарии прототипа | `prototype/app.js`, обработчик `act` |
| Персонажи и предметы-примеры | `ITEMS` / `QUESTS` в `prototype/app.js`, соответствующие исходные строки в генераторе |
| Браузерные диалоги и фокус | `prototype/styles.css` |
| Нативная структура Godot | `src/build_godot.py` и `godot/scripts/` |

Некоторые нейтральные оттенки иллюстративной карты и отдельных подложек заданы непосредственно в генераторе. Палитра токенов управляет основными семантическими цветами; это ещё не полноценный визуальный редактор тем.

## Иллюстрации

`world.jpg` — отдельный фон на основе пользовательского референса. `hero_cutout.png`, `echo_art.png`, `barton_art.png` и портреты — временные растровые материалы из коллажа. Замените их своими изображениями с теми же именами или измените ссылки в генераторе. Для финального игрового меню вместо вырезки героя предполагается настоящий viewport с 3D-персонажем.

Не считайте вырезанный из генерации портрет исходной моделью, текстурным атласом или PSD. Детали, которых нет в исходной картинке, в этом наборе не восстановлены.

## Шрифты

Векторные и браузерные макеты используют системные семейства: Arial / Liberation Sans для основного текста, Georgia / Liberation Serif для заголовков и стандартные fallback. На компьютерах с разными шрифтами метрики могут немного отличаться. **Бинарных шрифтов в архиве нет.** Для релиза нужно выбрать и подключить лицензированные игровые шрифты отдельно, затем проверить строки во всех локализациях.

## Дополнительные размеры

Макеты рисуются в опорном разрешении 1920 × 1080. HTML масштабирует весь холст и ограничивает ширину оболочки. Проверена работа оболочки без горизонтального переполнения при 1280 × 720, 1920 × 1080, 2560 × 1440 и 3440 × 1440.

Это **не** полная адаптивная компоновка игрового HUD под каждый монитор. Продакшен должен использовать anchors/containers, настройку масштаба текста и безопасных полей, а не просто уменьшение всего холста. Отдельная мобильная версия в этот комплект не входит.
