# Происхождение материалов и ограничения

| Материал | Источник и назначение |
|---|---|
| `references/world_reference.png` | Изображение визуального направления игры, предоставленное пользователем в этой беседе |
| `references/concept_board.png` | Сгенерированный ранее в этой беседе UI-концепт; не файл со слоями |
| `assets/art/world.jpg` | Кадрирование пользовательского референса под 16:9 |
| Портреты, `hero_cutout`, `echo_art`, `barton_art` | Вырезки из ранее сгенерированного коллажа; временные растровые иллюстрации, не модели и не финальный игровой арт |
| `assets/icons`, SVG-панели и карта | Геометрия, написанная специально для этого набора исходников |
| HTML, CSS, JavaScript, Python, GDScript | Исходный код, подготовленный для этого комплекта |
| Шрифты | Только системные названия и fallback. Файлы шрифтов не распространяются |

Архив не устанавливает права на первоначальный пользовательский референс и не представляет собой официальный UI-пак Genshin Impact или другой игры. Товарные обозначения и оригинальные ресурсы таких игр в новый векторный набор не копировались.

## Основание игровых решений

Использованы материалы Notion, прочитанные в этой беседе, и последующие уточнения пользователя. Основная страница: https://app.notion.com/p/3f18867306b180749a02c5ddb12d538a

Квесты и Гильдия Авантюристов: https://app.notion.com/p/3f48867306b181b89daafeed353b1894

Приоритет у уточнений: глобальный сюжет автономен; базовые характеристики неотрицательны; производные параметры могут быть отрицательными, кроме HP; легендарное снаряжение исключено из PvP-дропа. Макеты не сохранялись обратно в Notion и не меняли его содержимое.

Каэль, Сиэль, Торен, Бартон, Ривермут, суммы наград, предметы и цифры — демонстрационные данные для согласования интерфейса, а не утверждённый канон и баланс.
